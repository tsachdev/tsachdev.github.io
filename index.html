Graduation Ledger gate

A personal tool that lets AI agents help with one Gmail inbox, only with its owner's approval.

The Graduation Ledger gate sits between AI email assistants and a single Gmail account, owned and run by Tushar Sachdev for his own mailbox. It is not offered to anyone else, and nobody else can sign in to it.

What it does

  • An assistant connected to the gate can read unread messages in the inbox.
  • When the assistant wants to change something (mark a message read, move it to the trash, or save a draft reply), the gate holds the request. Nothing happens in Gmail until the owner approves that request on a private page with his passkey.
  • Every request and decision is written to a log, so the owner can see over time which kinds of action an assistant gets right.

Google access

The gate uses one Google permission, Gmail "read, compose and modify" (gmail.modify), for the owner's own account only. It never sends email and never deletes anything permanently; trashed messages stay recoverable in Gmail for 30 days.
